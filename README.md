## 🧭 About Me

- 🔭 Engineer at **[Zilliz](https://zilliz.com)**, working full-time on **[Milvus](https://github.com/milvus-io/milvus)** — the open-source, cloud-native vector database.
- 🧱 I spend most of my time in the **data plane**: index building, compaction, data coordination, storage formats and the scheduling that keeps it all moving.
- 🗺️ Recently deep in **geospatial (GIS) indexing**, **shard splitting**, and making large-scale clusters fail less and recover faster.
- 🐞 I enjoy chasing production bugs to the root cause — core dumps, memory safety and race conditions are my happy place.
- 💬 Ask me about vector search, Go/C++ systems programming, Pulsar/Kafka, or how a vector DB works under the hood.
